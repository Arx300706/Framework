# Archives

`brouillon/` contient les anciens POM et scripts, conservés sans modification.
Ils ne participent pas à la construction actuelle. Ne pas les exécuter comme
points d'entrée : utiliser les commandes du README à la racine.

L'ancienne copie `Framework/` est conservée dans la sauvegarde locale complète
`.local-backups/avant-rangement-20261016-085223.tar.gz` et dans l'historique Git
(commit d'introduction : `5a96a9d`). Son API Servlet est identique à celle conservée
dans `framework/lib/servlet-api.jar`. Ses classes compilées et ses copies de JAR
ne sont pas utilisées pour construire l'application.
